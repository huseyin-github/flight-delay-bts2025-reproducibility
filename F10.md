# Reported results and provenance

The two CSV files here were **transcribed programmatically from the authors' MATLAB console output** for Stage 29 on 29 October 2026. These files were **not independently recomputed** by the repository preparation process. The original MATLAB code generates the full-precision CSV files directly in the `Stage27_Full23_5Fold/` directory once it finishes; those machine-generated CSVs should supersede these console-transcribed, rounded summaries whenever available.

- `Stage27_FoldMetrics_transcribed.csv`: 115 fold/preset statuses; rounded fold metrics from the console printout.
- `Stage27_PooledOOF_transcribed.csv`: 23 preset names in manuscript order; pooled metrics are present only for 16 models completing all five folds.
- Completed native full-data fits: **82 of 115**; **16 of 23** presets have five complete folds.
- Exact GPR: 10 fold/preset attempts blocked by the memory guard. Other incomplete models were deferred or partially completed.
- Main published outcome among 16 completed models: Robust Linear, pooled RMSE **15.259 min**, MAE **10.516 min**, R² **0.93033** (274,691 chronological out-of-fold predictions).
- The reported computational training times exclude prediction, input loading and preprocessing; they are hardware-dependent.

`N/R` in the manuscript and blank/`NaN` here indicate **not evaluated across the complete five-fold protocol**, not zero error.

To regenerate full-precision results, run the MATLAB source using the exact authors' data extract and preserve the checkpoint.
