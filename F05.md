# Public data provenance and input contract

**Source:** U.S. Department of Transportation, Bureau of Transportation Statistics (BTS), TranStats, on-time performance, January 2025. Use the appropriate *marketing-carrier* or *reporting-carrier* table matching the authors' source snapshot and field definitions; these are different BTS tables and cannot be interchanged without verifying the resulting sample.

- BTS reporting carrier field details: https://www.transtats.bts.gov/TableInfo.asp?QO_fu146_anzr=b0-gvzr&gnoyr_VQ=FGJ
- BTS marketing carrier download: https://transtats.bts.gov/DL_SelectFields.aspx?QO_fu146_anzr=b0-gvzr&gnoyr_VQ=FGK
- U.S. BTS public site: https://www.transtats.bts.gov/

The authors' local analysis file is named `TranstatsData_Ayse4.xlsx`, and the code reads worksheet `TranstatsData_Ayse`. **That exact XLSX is not included in this repository**, and its checksum was not available when this package was prepared. For bitwise/source-identical replication, the authors should deposit the frozen, shareable input snapshot separately and add its checksum and link here, or verify that a freshly downloaded BTS extract produces the expected counts.

## Required variables (spelling in XLSX must be exact)

```
CANCELLED, DIVERTED, ARR_DELAY, DEP_DELAY,
DAY_OF_MONTH, DAY_OF_WEEK, MKT_CARRIER,
ORIGIN_AIRPORT, DEST_AIRPORT,
CRS_DEP_TIME, CRS_ARR_TIME, CRS_ELAPSED_TIME, DISTANCE
```

A BTS export may use different source column names (for example, `ORIGIN` and `DEST`). Such columns must be mapped explicitly before creating the Excel input; the codes must represent the same airport identifier categories used by the study. Do not silently substitute a different air-carrier indicator or a different BTS table.

## Reproduction checks built into the MATLAB analysis

- Original source extract: **599,013** rows in January 2025 (as reported by the study).
- Excluded: **18,740** cancelled and **1,316** diverted flights.
- Eligible completed flights: **578,957**; target `ARR_DELAY` in minutes, including negative/zero values.
- Development Jan 1–24: **447,066**; January 25–31 later test: **131,891**.
- Five fold training sizes: **172,375 / 225,076 / 280,333 / 337,480 / 390,901**.
- Five validation sizes: **52,701 / 55,257 / 57,147 / 53,421 / 56,165**.

If these counts differ, stop and verify the extract, report version and fields; do not change assertions to force a match.

## Data protection and distribution

The BTS source is publicly accessible. Raw hundreds-of-megabytes XLSX/CSV files are intentionally excluded from this GitHub source-code archive. The data license/terms should be checked at the BTS source before redistributing a frozen copy. No local drive paths, user identifiers, or checkpoint `.mat` files are published here.
