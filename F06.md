# Methods and validity notes

## Prediction task

Continuous `ARR_DELAY` (arrival delay, minutes) for completed flights **after departure**, using observed `DEP_DELAY` as one input. It is **not** a predeparture forecasting claim.

Predictor names and transformations are implemented in the Stage27 scripts. The four categorical columns are represented as categorical variables, with levels determined from the fold's training data; unknown validation levels map to the most frequent training category. Scheduled HHMM times become sine/cosine pairs. Other predictors: day of month, day of week, marketing carrier, origin, destination, scheduled elapsed time, distance and observed departure delay.

Delay cause attribution (`CARRIER_DELAY`, `WEATHER_DELAY`, `NAS_DELAY`, `SECURITY_DELAY`, `LATE_AIRCRAFT_DELAY`) is excluded; it is retrospective and can disclose target information. Realized taxi and other unavailable operational fields are also excluded.

## Temporal validation

Expanding train Jan 1–9, 1–12, 1–15, 1–18, 1–21; validation Jan 10–12, 13–15, 16–18, 19–21, 22–24. The five validation windows contain 274,691 distinct flights. Metrics are pooled from the out-of-fold predictions; they should not be confused with a mean of the five per-fold RMSE values.

The later Jan 25–31 test (131,891 flights) was inspected as part of numerical auditing; it is **not** a never-touched test. The 5-fold metrics and the additional later-period audit are reported separately.

## Model configurations and model selection

The source specifies the 23 MATLAB Regression Learner configurations with their original nominal hyperparameters. No separate global grid/random/Bayesian/nested tuning is claimed. `Auto` refers to MATLAB's native implementation. `fitrkernel` intrinsically approximates kernels, which is a distinct, documented preset; it is not exact GPR.

For native full-data five-fold runs, **16** of the 23 model presets completed all five folds. Robust Linear ranked first by pooled RMSE and MAE among these 16. Incomplete presets must not be assigned pooled scores or ranked with complete presets.

## Computational constraints and numerical audits

The Stage27 GPR guard rejects an exact kernel matrix requiring more than 128 GiB. The single double-precision N×N matrix itself requires roughly 221 GiB at the first fold and 1,139 GiB at the fifth fold, before further workspace; exact GPR was therefore not executed. Some full-N `fitrsvm` and `fitrkernel` runs were deferred due to training time. Safe resume and single-preset scripts permit completing individual folds without changing model settings, using the same source input and checkpoint.

`fitlm(...,'RobustOpts','on')` may emit an `Iteration limit reached` warning in a fold even if it returns predictions. `NOT_EXPOSED` convergence metadata is not a verified convergence claim. The authors also performed a sparse-QR IRLS numerical audit (Stage24/25) whose implementation is **not identical** to MATLAB's native `fitlm` fit. Supplementary comparisons and seven-day bootstrap estimates should not be conflated with the native five-fold leaderboard.

## Files and dependencies

- `scripts/main/`: Stage27, Stage28 and Stage29 versions that generated the native five-fold leaderboard; use these first.
- `scripts/audits/`: supporting Stage21–26 auditing code. They require earlier checkpoint and prediction files, some of which **are not contained here**. Stage26 in particular references `FlightDelay_Stage16_FinalTest.mat`; until that file or an equivalent rerun script is supplied, the full audit chain is **not independently executable** from this archive alone.
- `scripts/exploratory/`: Stage20 and Stage23 screening; these **use reduced training sets and/or approximations for certain configurations** and must never be represented as the native full-data five-fold experiments.
- `results/`: author-reported console summaries, not independently rerun results.

## Interpretation

Numerical superiority of Robust Linear over ordinary Linear and Linear SVM in pooled RMSE is small and is not a universal or statistically established algorithmic superiority claim. Report predictive performance and computational feasibility for this specific January 2025 postdeparture task. No causal effect or demonstrated improvement in costs, emissions, safety, or passenger outcomes is inferred.
