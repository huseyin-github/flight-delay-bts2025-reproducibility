# Public repository checklist

- [ ] Review the source files to ensure no local credentials, private paths or personal information are present.
- [ ] Confirm the publicly visible dataset description matches the actual source workbook and BTS table.
- [ ] Run `python tools/verify_reported_results.py` to check transcribed table consistency.
- [ ] Prefer replacing `results/*transcribed.csv` with the original machine-generated Stage27 CSV exports from the `Stage27_Full23_5Fold/` folder when available.
- [ ] Provide the source workbook checksum or a frozen dataset archive DOI/link if redistribution is permitted. Without the exact snapshot, full bit-for-bit replication cannot be guaranteed.
- [ ] Provide actual installed MATLAB version and toolboxes, computer CPU/RAM/OS from the original runs; `R2024b or later` is a code requirement, not proof of the version used for all runs.
- [ ] The supplementary Stage26 audit uses `FlightDelay_Stage16_FinalTest.mat`, which is not included; add the authors' associated reproduction scripts and inputs before claiming that audit is entirely reproducible.
- [ ] After making the GitHub repository PUBLIC, paste its actual URL into manuscript Data Availability / Code Availability and Response to Reviewer. Do not add a guessed URL.
- [ ] Optionally choose and add an explicit software license if the authors wish to permit reuse beyond examination.
